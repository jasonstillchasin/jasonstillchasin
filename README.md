I build things that try to prove themselves wrong. Mostly quantitative research, where I pre-register the tests and publish the null results too.

### 🔬 research

**NULLIUS**, a reality check for LLM-driven factor selection. The agent beats a 200-draw bootstrapped null decisively, but is statistically indistinguishable from budget-matched random search. [Paper on SSRN](https://papers.ssrn.com/abstract=7190318).
